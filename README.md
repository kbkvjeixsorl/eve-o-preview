## 🕹️ Overview

EVE-O Preview gives EVE Online players thumbnail previews of all running game clients, allowing fast switching and layout management for multiboxing.

Whether you're a newcomer or a veteran, EVE-O Preview provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Live Thumbnails** | Real-time miniature previews of every active EVE client |
| **Click-to-Focus** | Instantly switch to any client by clicking its thumbnail |
| **Layout Profiles** | Save and restore thumbnail positions for different setups |
| **Hotkey Switching** | Keyboard shortcuts for cycling between active clients |
